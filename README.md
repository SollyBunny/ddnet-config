# DDNet Config

This repo contains sane defaults for DDNet and other clients

These settings are designed for [Supported Clients](#supported-clients), but other clients will work to a lesser degree

## How to use

1. [Download the config](#downloading)
2. Extract the zip into the correct [config directory](#config)
3. Play

## Supported clients

This can be used with any client but here are the ones this is designed for
1. [DDNet](https://github.com/ddnet/ddnet/)
2. [TClient](https://github.com/sjrc6/TaterClient-ddnet)
3. [SollyClient](https://github.com/sollybunny/ddnet) (must be self compiled)

## Downloading

Here are quick links to download the config
1. [Sane](https://github.com/SollyBunny/ddnet-config/archive/refs/heads/sane.zip)
2. [Solly](https://github.com/SollyBunny/ddnet-config/archive/refs/heads/solly.zip)

The config can be manually downloaded as a `.zip` using the `download zip` button inside the blue `Code` button

## Config Directories

Config should be placed in these folders

Make sure the config is not in a folder (eg: `sane`) inside the config folder

### On Windows:
* Old: `%appdata%\Teeworlds`
* New: `%appdata%\DDNet`

### On Linux:
* Old: `~/.teeworlds`
* New: `~/.local/share/ddnet`

### On macOS:
* Old: `~/Library/Application Support/Teeworlds`
* New: `~/Library/Application Support/DDNet`
